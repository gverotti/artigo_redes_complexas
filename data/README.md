# Dados

Os arquivos desta pasta **não são versionados** (ver `.gitignore`). Cada integrante baixa localmente.

| Arquivo | Origem | Uso |
|---|---|---|
| Dados do artigo (4.514 PMEs italianas) | [Supplementary Material do artigo](https://www.frontiersin.org/articles/10.3389/frai.2019.00003/full#supplementary-material) | Replicação (etapas 2 e 3) |
| `LoanData.csv` (~330 MB) | [Bondora — Public reports](https://www.bondora.com/en/public-reports) | Extensão opcional (etapa 4) |

Coloque os arquivos brutos em `data/raw/` e os processados em `data/processed/`.
