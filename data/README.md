# Dados

As bases ficam só nas nossas máquinas. A pasta `data/` está no `.gitignore` porque os arquivos são grandes demais
para o GitHub (o limite é 100 MB por arquivo). Cada um de nós baixa e coloca os arquivos aqui.

| Arquivo | De onde vem | Para que usamos |
|---|---|---|
| Base do artigo (4.514 PMEs italianas) | [Supplementary Material do artigo](https://www.frontiersin.org/articles/10.3389/frai.2019.00003/full#supplementary-material) | Replicação (etapas 2 e 3) |
| `LoanData.csv` (~330 MB) | [Bondora, Public reports](https://www.bondora.com/en/public-reports) | Extensão opcional (etapa 4) |
| `loan_dataset_investor.xlsx` (~175 MB) | Bondora, Go & Grow | Não usamos. Só tem o desempenho dos empréstimos, sem dados do tomador |
